# Zen Compact Transparent HDR Guard v0.4.5 — independent selected-tab colour editor

## Changes

- Move the existing selected-tab colour picker, native tab right-click menu command and global Zen/Zia selected-colour CSS from Site Folders into HG, so they remain available without Site Folders installed. Reuse the exact saved preference `zsf.selected-tab-color.v1`, alpha range 0–100 and default #ffffff at 8% opacity. No data migration or preference reset is performed.
- Keep the 310px non-modal editor, instant preview, cancel/reset/save, compact-sidebar hold, light palette, glass styling, right-aligned sidebar anchor and original menu wording. Existing Zia hover-card glass and HG custom blur still apply; split-view wrappers receive the selected colour.
- Register an independent `selected-color.uc.js` module in Sine. The original HDR and SDR scripts, streaming video actors, intervals, PageThumbs and PiP logic remain byte-identical.

## SDR/HDR and Zia compatibility

- This change touches only selected-tab appearance and its non-modal popup; the HG 10px user glass setting, first-frame unified sidebar and card styling, Zia hover animations and split rendering remain under their existing rules.
- Video-protected areas retain the previous HG and Zia compositor gates. HDR may still look **dim or washed out** with a visible blur overlay; Bilibili instant-glass remains a deliberate exception that can bypass strict HDR detection. The existing compositor and context-menu outline experiment stays **default-OFF**.
- When Site Folders v0.9.3 is installed, that mod no longer creates the selected-colour command or stylesheet. Without Site Folders, the HG right-click command and editor continue to function.
- Legacy historic IDs and the `--zsf-selected-tab-fill` variable are retained for compatibility; their owner is now HG.

## Validation and hardware limitations

- Automated Node.js unit tests cover preserved saved colours, invalid stored values, right-click command ownership, CSS/Zia split rules, live preview, cancel, reset, save, and independent operation with no Site Folders JavaScript. CI additionally runs previous HDR/SDR/glass regression checks and deterministic performance simulations.
- **macOS 27.2, Apple Silicon and OLED hardware acceptance not performed by automated CI.** Actual hardware testing is required for menu position, non-modal pop-up glass, SDR/HDR video compositor transitions, user-configured blur strength and selected-tab paint under Zia and Split View.
- No video classifier or compositor timing experiment is added. This release does not claim to fix the pre-existing macOS Gecko blur/ghost-outline limitations.

## Rollback

- For immediate rollback of the selected-colour editor, disable the HG MOD in Sine, or install the previous v0.4.4. If running older Site Folders v0.9.2, it contains the prior editor; avoid loading both owners simultaneously, restart Zen after MOD changes.
- Full HG release rollback: [v0.4.4](https://github.com/kcussiefil/Zen-Compact-Transparent-HDR-Guard/releases/tag/v0.4.4), commit `018da58f7affa68f82cab0638464480087eabe71`, backup branch `backup/v0.4.4-before-v0.4.5`. Turn Unified HG **OFF** (or disable the MOD) for immediate original-appearance rollback; old HDR options remain default-OFF.

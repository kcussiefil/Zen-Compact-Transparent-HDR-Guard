# Zen Compact Transparent HDR Guard v0.2.0 (020)

**Zia v2.118.0 video glass compatibility, retaining the v0.1.9 stream classifier.**

- Remove obsolete forced-opaque Zia sidebar and hover-card paint on YouTube/Bilibili video pages.
- Remove unconditional `will-change: auto !important` that blocked genuine blur on video pages when Zia's **Blur over video** was enabled.
- Exclude browsers showing live video from the legacy ordinary-page Transparent Mode styling; Zia now owns the video compositor on selected/split panes while actual sidebar/overlays are open.
- Keep optional confirmed-SDR glass, YouTube/Bilibili HDR recognition, generic HTML5 classification, manual URL rules, and user-configurable ordinary-page sidebar styling unchanged.
- Clarify Zia-native blur vs legacy opt-in in Sine settings and add CI regression checks.

### Enable / test
1. Update Zia to v2.118.0 and enable **Look → Blur over video**.
2. Update this MOD to **0.2.0** through Sine; restart Zen.
3. Check HDR with sidebar hidden (should retain native look); reveal sidebar (true glass; some dimming is acceptable), then hide it again (must restore).
4. Check SDR, ordinary pages, Zen Site Folders v0.7.6 preview, and a non-YouTube HTML5 video page.

**Upstream limitation:** Zia explicitly warns Blur over video changes video rendering and can remove HDR while blur is visible. No video brightness filter or persistent compositor promotion is added.

Automated syntax/Node regressions pass; user's macOS 27.2/OLED visual compositing remains the required acceptance test. To revert, reinstall v0.1.9 at commit `c2b1c048cc635c5023296a7f09854e872803243e`.

# Zen Compact Transparent HDR Guard v0.3.2 — First-frame HG preview glass without extra polling

## Changes

- Fixed a specific first-visible-frame styling dependency with **Zia v2.121.0** and **Zen Site Folders v0.7.6**. Site Folders opens its group preview, then synchronously copies computed styles from Zia's *potentially hidden* native preview card. In v0.3.1, HG's preview selector excluded `[hidden]` sources, allowing the group card to start with Zia's `blur(24px)` before another sync supplied HG's custom value.
- In v0.3.2, HG's opt-in preview-card rule is also resolved for hidden native Zia card DOM, **before the preview first appears**. Thus Site Folders' synchronous source-style read can copy the actual configured HG value, e.g. **10px**, rather than a transient Zia 24px. **5px remains only the existing fallback when the custom Sine variable is absent**; a loaded 10px user setting is not first painted at 5px by this rule.
- A hidden card remains hidden via the upstream `[hidden] { display: none !important; }` rules in Zia and Site Folders. This does **not** add a hidden-page GPU blur, alter card position/shape/animation, or force a video compositor layer.
- The existing SDR/HDR/unknown video safety conditions and explicit Bilibili bypass remain unchanged. The preview-card option remains **default OFF** and requires Zia card blur to be enabled.

## SDR/HDR and Zia compatibility

- The opt-in preview-card style still follows the existing HG gating for confirmed SDR, separately authorized HDR, the explicit Bilibili fast path, and normal non-video pages. Unknown and protected HDR videos are **not** silently treated as SDR.
- Normal Zia blur policy, Site Folders' own card positioning/animations and the user's Sine-defined blur value remain authoritative. Hidden source styling is calculated, not displayed.

## Validation and hardware limitations

**Performance and non-regression checks:**

- The ONLY runtime CSS change (ignoring an explanatory comment) is removal of the `:not([hidden])` condition from **one existing preview-card selector**. All declaration values, custom color/opacity/blur variables, the entire remainder of `chrome.css` and the Sine preferences are **byte-identical to v0.3.1** after restoring that single gate. The CI verifies this with the canonical v0.3.1 Git blob SHA.
- All v0.3.1 JavaScript remains byte-identical, including the 1000 ms chrome watchdog, immediate TabSelect/player/pref listeners, 100 ms unknown-site fallback, 180 ms video child monitor, Glance and Bilibili logic. No timers, observers, actor probes, layout reads or DOM writes were added.
- The prior 60-second v0.3.0-v0.3.1 virtual-time scheduler benchmark is re-run unchanged to guard against losing v0.3.1's work reduction.
- A new **10,000-preview synthetic first-frame comparison** models Site Folders' read-from-hidden-Zia-and-copy-inline behavior. Expected transient Zia 24px readings under this model: v0.3.1 **10,000 / 10,000**, v0.3.2 **0 / 10,000**; computed-style reads and style writes remain the same in both models.
- **Important:** this verifies the model and strict source-code performance non-regression. It is **not** proof of equivalent GPU frame time, macOS compositor stability or a measured FPS improvement. The only behavioral change is how hidden card CSS is *resolved*, not whether it is drawn.

**Verification requirements:**

- Run GitHub Actions syntax checks, full Node regression suite, 60s virtual scheduler replay and 10k first-frame comparison. Do **not** merge if any fails.
- On macOS, test Zia tab card, Zia native folder card, and Site Folders group card, including a custom 10px blur and repeated first opens; SDR and HDR video pages; Glance open/close; and sidebars with video playback. An unrecognized video or a GPU compositor transition may still delay safe custom HG painting; the patch does not force unknown HDR streams to SDR.
- Actual Zen macOS OLED HDR/SDR **hardware verification was not performed** by CI. If the blur still flashes after updating, further on-device paint analysis is needed rather than claiming complete repair.

# Zen Compact Transparent HDR Guard v0.4.6 — Calmer-compatible selected-tab colour placement

## Changes

- Move the existing **變更選取分頁顏色** native tab context-menu command to immediately **before Zen's Change Icon** item, sharing the same native insertion anchor and separator-bounded section as Zen Site Folders v1.0.9's **建立群組** command.
- This enables the existing Zen Calmer Context Menu sorting control to reorder the two independently installed actions **within that one section**, regardless of MOD load order. No cross-separator sorting or modification of Calmer itself is attempted.
- Prefer native `context_zen-edit-tab-icon`, falling back to Bookmark Tab, Bookmark Selected Tabs and Duplicate Tab if unavailable. Do not insert, delete, hide, or move native separators. In particular, preserve Zen's `edit-tab-icon + menuseparator` sibling relationship.
- Keep the menu action ID `zsf-change-selected-tab-color`, picker wording, settings store `zsf.selected-tab-color.v1`, saved opacity, 310px non-modal colour editor, preview/cancel/reset/save and mouse/keyboard handlers unchanged.

## SDR/HDR and Zia compatibility

- HDR/SDR compositor, codec recognition, Bilibili bypass, Zia glass surfaces, selected color CSS painting, split-view handling and all HG preferences remain byte-identical to v0.4.5 aside from the editor version marker and its insertion position.
- HDR videos may still look **dim or washed out** while a translucent overlay promotes composition. **Bilibili** instant-glass remains the existing deliberate exception to conservative HDR protection. The macOS context-menu black-outline experiment remains **default-OFF**.
- Zen's native tab right-click menu is untouched apart from the position of the one HG-owned entry. Zen Calmer Context Menu continues to apply its own grouping/ordering and respect the user's previously saved menu order.

## Validation and hardware limitations

- Added Node.js tests exercise the real `installTabColorMenu` function with native XUL-style menu fixtures, including both MOD loading orders, missing Change Icon fallback, unchanged menu command binding and native hidden-separator adjacency. Existing Node.js CI still runs all HDR/SDR, Zia, compositing, selected color, release policy and deterministic performance tests.
- **macOS Apple Silicon and OLED hardware acceptance has not been performed by automated CI**; actual hardware testing is required for the final right-click positioning, Calmer settings-to-popup synchronization, SDR/HDR video stability and the non-modal picker. Automated checks cannot certify third-party Calmer integration on a real installed Zen profile.
- No new polling, observers, video detection changes, blur strength changes or default-ON experiments are introduced.

## Rollback

- Reinstall HG **v0.4.5** through Sine or [GitHub Releases](https://github.com/kcussiefil/Zen-Compact-Transparent-HDR-Guard/releases/tag/v0.4.5), commit `2797280aefa5444b4e951b66aebe0b59b99eac57`; original main is preserved as `backup/v0.4.5-before-v0.4.6`.
- For immediate visual rollback, turn Unified HG **OFF** (or disable the MOD in Sine); the legacy HDR custom glass and context-menu outline options remain **default-OFF**. No stored selected-tab color data migration or preference reset is needed when reverting the menu position.

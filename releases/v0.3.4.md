# Zen Compact Transparent HDR Guard v0.3.4 — Glance foreground glass recovery

## Changes

- Fix the v0.3.3 overlap: the unified HG compositor excludes Glance, while the old Glance compositor excludes visible preview cards. As a result preview surfaces could remain transparent with no effective background blur. This release adds a separate, preference-gated foreground handoff for an actual visible HG overlay.
- With the existing default-OFF `mod.compacttpr.glanceglass` ON, Unified HG ON and the corresponding Zia blur preference ON, the selected Glance foreground receives the same `will-change: transform` promotion only while the floating sidebar, a visible Zia/Site Folders card, Site Folders colour editor, URL/search popup or new-tab floating bar is visible. The existing HG blur (for example 10px), colour and transparency are unchanged; hidden native Zia cards are excluded from GPU promotion.
- The Glance checkbox OFF preserves existing v0.3.3 behaviour as an immediate opt-out.

## SDR/HDR and Zia compatibility

- As in the v0.3.3 appearance-first model, SDR, HDR or unknown video may temporarily appear dim or washed out while a Glance foreground overlay is visible. Closing Glance or the last matching overlay removes HG's new CSS compositor eligibility. macOS/Gecko hardware may not restore HDR brightness on the same frame, so real-device verification remains mandatory.
- Bilibili instant-glass behaviour is unchanged. Normal-page promotion remains excluded during Glance. The existing Glance one-frame non-video recovery code, HDR protection, Zia matching preferences, Site Folders preview geometry and video classifier are unchanged. This is CSS-only apart from the MOD version, tests and documentation; no new JavaScript, observer, actor, timer or polling was added.
- A CSS request for `backdrop-filter` cannot guarantee actual page pixels are available for blurring under every GPU arrangement. Avoid near-100% transparency over video.

## Validation and hardware limitations

- The complete Node.js regression suite and new v0.3.4 Glance opt-in / visibility / Zia preference / safe-compositor tests are required to pass in CI before release. Prior virtual-time scheduler, video and 10,000-preview first-frame tests remain in the suite.
- **Actual macOS OLED HDR/SDR hardware verification not performed.** CI does not measure Gecko's real first frame, backdrop-filter pixels, Glance transparency, GPU performance or HDR brightness recovery. Test Glance alongside sidebar, native card, Site Folders card, URL/new-tab popup on ordinary web pages, SDR YouTube and 4K HDR YouTube; close Glance and all cards to confirm no residual dimming. Any failure requires further hardware investigation.

## Rollback

- Immediate Glance-only rollback: set the Sine preference `mod.compacttpr.glanceglass` **OFF** (default-OFF). To disable unified appearance too, switch `mod.compacttpr.unifiedhg` OFF.

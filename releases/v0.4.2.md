# Zen Compact Transparent HDR Guard v0.4.2 — opt-in visible preview-card blur stability experiment

## Changes

- Add a **default-OFF macOS-only** Sine preference, `mod.compacttpr.previewcardstability`, to test whether predeclaring `will-change: backdrop-filter` on visible card surfaces avoids the brief loss of blur observed while a separate background tab loads.
- Apply the hint only to Zia's native tab/folder/tip cards and the independent Site Folders hover card, **when each card is visible** and the HG unified theme and Zia cards blur are enabled. Do not alter the configured HG background colour, opacity or blur amount (10px remains 10px), animation, card size, menu, page, or sidebar. **This is an unverified GPU compositor hypothesis, not a verified fix.**
- Respect protected root `zia-video`, DOM fullscreen, customization and selected Glance-overlay exclusions; do not force blur where Zia intentionally protects video. Leave Site Folders' own code and Zia's own files untouched.

## SDR/HDR and Zia compatibility

- Do not change any compositor rule for browser content, page transforms, PiP, Zia video-state detection, SDR/HDR recognition, Bilibili logic, scripts, polling, or existing card-paint CSS. The new hint could still change macOS GPU layer allocation while visible cards are open; verify video brightness before considering it stable.
- Zia/HG blur can still make an HDR video temporarily dim or washed out with an overlay visible. This change does not make HDR blur safe. Bilibili's existing instant-glass exception still bypasses HDR checking when enabled.

## Validation and hardware limitations

- CI runs Node.js syntax checks, full Node regressions, deterministic performance simulations, and the release-policy test. New tests assert the new option defaults OFF and the CSS is card-only, macOS-only, Zia-blur-gated, excludes protected video/Glance, preserves existing 0.4.1 menu CSS, and does not change any paint, transform or page-promotion properties.
- Actual macOS 27.2 OLED hardware rendering **not verified** by automated tests. To verify, update via Sine, enable only the new card-stability option, and keep HG unified theme and Zia's card blur enabled. Hover native tab/folder cards and Site Folders' group card while opening several links in background tabs. The card must stay consistently blurred before, during and after loading with the existing HG blur amount and no first-frame Zia-to-HG swap. Check YouTube SDR/HDR and Glance separately. Compare the new switch ON vs OFF in the *same* session/profile, and report whether the issue changes.
- A CSS will-change hint does not guarantee WebRender will reuse its blurred surface while background browser layers change. If no improvement, disable the option; next investigate computed backdrop-filter values and Gecko compositor logs rather than stacking more overrides.

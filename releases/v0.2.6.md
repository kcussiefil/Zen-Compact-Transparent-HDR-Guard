# HDR Guard v0.2.6 — Optional unified preview-card glass (Zia + Zen Site Folders)

## New feature
Add independent Sine setting **「預覽卡片跟隨 HDR Guard 毛玻璃（單一分頁與群組）」**, preference `mod.compacttpr.previewcardcustomblur`, **default OFF**.

When enabled, all four **visible** preview-card surfaces use exactly the same configured glass variables as HDR Guard's sidebar and v0.2.5 URL/search popup:
- Zia single-tab preview `#zia-tab-card`
- Zia native folder preview `#zia-folder-card`
- Zia tip card `#zia-tip-card`
- Zen Site Folders 0.7.6 independent hover preview `#zsf-folder-hover-card`

Colors use `--mod-compacttpr-customcolor-final`, transparency uses `--mod-compacttpr-transparentvalue`, and radius uses `--mod-compacttpr-customblur`. This overrides the upstream Zia/Site Folders fixed 76% opacity and `blur(24px) saturate(1.6)` but preserves card geometry, animation, shadow and internal layout.

## HDR safety
- Requires Zia's **preview-card blur** preference (`zia.cards.blur`) and HDR Guard's overall transparent-mode option.
- Ordinary pages are eligible; confirmed SDR requires its existing opt-in. Confirmed HDR requires its separate v0.2.2 opt-in **and** Zia Blur over video. Bilibili fast path retains its existing explicit user exception. Unknown/protected video stays upstream Zia.
- **No new video compositor rules.** This change introduces no `will-change: transform`, `backface-visibility`, browser layer changes or brightness/color filters. Zia and Site Folders retain their `:has(visible-card)` compositor lifecycle.
- Because Gecko's video blur on macOS may wash out HDR while cards are visible, **OLED hardware acceptance is still required** to verify HDR brightness recovers as soon as the card closes. Node tests cannot prove macOS GPU behavior.

## Validation
New Node regression suite covers disabled-by-default and immediate preference rollback, the four card targets, user variable parity, higher specificity than Zia 2.118 and Site Folders 0.7.6 CSS, visible-only scoping, HDR/SDR/unknown/Bilibili policy, and no persistent video composition. Existing v0.2.5 Popup and Bilibili tests remain active.

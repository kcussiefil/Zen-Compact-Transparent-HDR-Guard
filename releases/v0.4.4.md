# Zen Compact Transparent HDR Guard v0.4.4 — remove failed preview and Glance compositor experiments

## Changes

- **Cleanup only:** remove the default-OFF `mod.compacttpr.previewcardstability` Sine preference and all v0.4.2/0.4.3 preview-card compositing experiment CSS. Both hypotheses failed macOS hardware testing: card-level `will-change: backdrop-filter` did not prevent transparent frames, and suppressing inactive background page promotion also did not resolve the blur flash. Do not replace them with another speculative override.
- Remove the default-OFF `mod.compacttpr.glanceglass` Sine preference, its dedicated v0.3.4 visible-Glance and v0.3.0 Glance recovery/foreground CSS, the `glance-recovery.uc.js` script and its `theme.json` registration. The user's working configuration already keeps Zia's **“A glance shows on its tab as a small picture of the page”** OFF; their HG sidebar glass works without the Glance fix enabled.
- Remove obsolete tests that asserted the existence of those features and add strict retirement/safety regression coverage. Keep historical v0.3.x/v0.4.x release notes and rollback tags intact.

## SDR/HDR and Zia compatibility

- Keep the unified HG custom colour/transparency/blur (including the user's 10px value), ordinary sidebar and card visual CSS, Zia and Site Folders selectors, URL/new-tab popup, Split View, native Glance overlay/background **safety exclusions**, Bilibili fast path, all remaining video/SDR/HDR actors, PiP and all existing timing logic **unchanged**.
- Zia's core hover cards and Site Folders continue to own their opening and closing animations; this release does not fix the background-tab blur flash, which is now being investigated as a possible Gecko/WebRender backdrop sampling issue. A match with any specific Gecko bug has **not been conclusively proven**.
- Preserve the v0.4.1 macOS context menu border-only CSS byte-for-byte, including the system window shadow needed to paint backgrounds. The user's menu background and submenu were restored, but **dark corner outlines remain**; do not adjust menu styling in this cleanup.
- HDR videos may still look **dim or washed out** while a blurred overlay is open. Bilibili instant-glass remains an explicit exception that may bypass HDR detection when enabled; disable it if strict video protection is needed. The remaining menu outline experiment is default-OFF.

## Validation and hardware limitations

- CI must pass Node.js syntax checks, complete Node.js regression suite, release-policy assertions, and deterministic performance simulations before publication. The new retirement test checks that the removed Sine preferences, loaded script and dedicated CSS are absent, while baseline unified HG card blur, generic Glance exclusions, Zia split-view/selected-page handling, core video actor hashes, and the v0.4.1 menu safety rules remain intact.
- **macOS 27.2 / Apple Silicon / OLED hardware acceptance not performed by automated CI.** The expected result is that the two ineffective Sine toggles disappear without visual changes to normal HG 10px glass, Zia/Site Folders hover cards, normal Glance (with Zia's small-page-picture option OFF), SDR/HDR playback, video PiP or right-click menus. Mac hardware testing remains required to confirm no regression.
- This version is a removal of explicitly failed code, **not** a claim to have resolved Gecko WebRender blur sampling. No background browser composition changes are retained from v0.4.3.

## Rollback

- For immediate rollback of HG custom glass, turn **Unified HG theme OFF** in Sine, or disable the HG mod; both options remain available. The preserved context menu outline experiment is **default-OFF** and can also be turned OFF independently. Restart Zen if Sine caches the stylesheet.
- Full release rollback: [v0.4.3](https://github.com/kcussiefil/Zen-Compact-Transparent-HDR-Guard/releases/tag/v0.4.3), commit `3995bdba031e18cd3d58ae564a61e02cb4620069`, backup branch `backup/v0.4.3-before-v0.4.4`. That release still contains both retired default-OFF experimental toggles if a specific older configuration must be reconstructed.

# HDR Guard v0.2.5 — Fix Zia URL/search popup glass overriding custom blur

## Root cause
Zia v2.118.0 uses `:root:not(#zia-none):not(#zia-none-2) #urlbar#urlbar...` with `!important`, making its popup 78%-opaque / `blur(24px) saturate(1.6)` rules higher specificity than HDR Guard's v0.2.3/v0.2.4 popup rules. Thus the custom popup checkbox appeared ineffective even though HDR Guard was already using the same three custom variables as the sidebar.

## Fix
- Raise only the three HDR Guard popup CSS selector branches above Zia 2.118's specificity using matching-safe ghost-ID `:not(...)` selectors. This is independent of stylesheet loading order.
- The popup uses exactly the same variables as the floating sidebar: `--mod-compacttpr-customcolor-final`, `--mod-compacttpr-transparentvalue`, `--mod-compacttpr-customblur`.
- Preserve the dedicated opt-in popup switch (default OFF) and Zia's own **The pop-up is see-through, the page blurred behind** preference.
- Preserve Zia's opposite light/dark popup solid background exception for text contrast.
- Preserve v0.2.4 immediate Bilibili rule, HDR/SDR classifier, HDR custom-glass switch and Site Folders behaviour.
- **No new video-compositor or brightness modifications**: no `will-change`, `backface-visibility`, persistent transform, or video filter. Zia continues to composite video only when its overlays are displayed.

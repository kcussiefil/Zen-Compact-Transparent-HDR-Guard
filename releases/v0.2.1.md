# Zen Compact Transparent HDR Guard v0.2.1 (021)

Fix the SDR custom glass switch not having any visible effect when **Zia 2.118 → See-through surfaces keep blurring a video behind them** is enabled.

## Why 020 did not react
Zia intentionally clears root `[zia-video]` when Blur over video is on, while maintaining `browser[zia-video]` on the selected/split video content. In 020, HDR Guard's classification loop was disabled whenever the root flag was absent and its custom CSS also required that flag. As a result, switching SDR custom glass on or off could not change the sidebar.

## 021
- Enable the optional SDR classifier when Zia Blur over video is enabled AND a visible video browser exists, regardless of the root video flag.
- Allow `data-zcth-sdr-glass` to select the HDR Guard's custom sidebar blur, background, translucency and height in either Zia video-flag mode.
- Keep **SDR custom glass OFF** = Zia native blur; **ON** = HDR Guard custom glass only for confirmed SDR. HDR or unknown classification never enables custom SDR overrides.
- Keep the old protected-video mode when upstream Blur over video is off; preserve HDR priority, Bilibili/YouTube/manual rules, regular pages, split-screen handling and Site Folders compatibility.
- No unconditional `will-change: transform`, video brightness filters, or edits to Zia/Site Folders.
- Automated tests cover live SDR checkbox switching, native Zia root video flag changes, HDR priority, disappearing video and the stylesheet selectors.

**Important:** macOS 27.2 OLED HDR colour/brightness is not verifiable by Node CI. Test with Zia Blur over video ON; first confirm that an SDR video is recognized, then toggle the custom SDR style. Finally test HDR with the sidebar hidden, opened and closed.

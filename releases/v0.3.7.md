# Zen Compact Transparent HDR Guard v0.3.7 — Video-independent sidebar geometry

## Changes

- Remove a real CSS state discontinuity: original HG positioned the compact floating sidebar within an SDR/HDR video eligibility selector, so asynchronous stream classification could withdraw and reapply toolbox top, height, transform, native background visibility and titlebar clipping. The original sizing and animation conditions now remain independent of video state while the protected glass paint retains its legacy video gating.
- Remove HG's duplicate native browser-page compositor promotion for ordinary floating-sidebar hover. Zia 2.121.4 already promotes the browser layer when its own overlay is visible and video blur is permitted. HG still handles visible Zia/Site Folders card and popup compositing without promoting hidden cards.
- Retire the unsuccessful v0.3.6 YouTube-only hidden-pane promotion experiment and its extra URL marker, restoring the original v0.3.5 URL helper byte-for-byte. No YouTube page-script enlargement, PiP black-bar or right-click sidebar shake changes.

## SDR/HDR and Zia compatibility

- Preserve the user's first-frame custom HG blur (such as 10px), opacity, colours, actual sidebar dimensions and existing animation gates. The geometry patch covers the same four original compact/single-toolbar and collapsed/expanded preference combinations without adding transitions, animations, timers or GPU promotions.
- The existing legacy SDR/HDR detection and Bilibili instant path are not modified. HDR video may be temporarily dim while an actual glass overlay is visible and should return to full brightness after it closes. The native compositor is not promoted continuously. Glance repair stays default-OFF; Zia Glance thumbnails should remain disabled for the separately known thumbnail issue.
- With Unified HG OFF, legacy protected glass paint can still change on real video classification; unlike previous releases this does not change the sidebar's placement or clipping. No guarantee of eliminating every native Gecko compositor brightness transition is made.

## Validation and hardware limitations

- GitHub CI performs all Node.js regressions, syntax checks, release-policy checks and deterministic scheduler/preview benchmarks. New tests validate video-independent geometry, all original height/visibility preferences, unchanged first-frame custom blur and the handoff of normal sidebar compositor ownership to Zia.
- **macOS OLED HDR/SDR testing not performed on actual hardware.** Reproduce the reported YouTube sidebar flashing while webpage pixels remain unchanged, then check SDR/HDR, playback startup, pause/resume, sidebar close/reopen, Glance thumbnails OFF, Bilibili and PiP. Static tests cannot confirm visible flicker is fixed.

## Rollback

- Disable `mod.compacttpr.usecompacttransparent` in Sine to revert HG as a whole. Disabling only Unified HG does not disable the video-independent geometry rule.
- Full rollback: install [v0.3.6](https://github.com/kcussiefil/Zen-Compact-Transparent-HDR-Guard/releases/tag/v0.3.6), SHA `172c62dfab1381407fc679f02e628e1606292f93`; backup branch `backup/v0.3.6-before-v0.3.7`. Restart Zen after changing Sine's installed MOD.

# Zen Compact Transparent HDR Guard v0.4.0 — macOS right-click menu outline-only correction

## Changes

- Restrict the experimental menu feature to the reported issue: **excessively dark outlines around the rounded corners** of Firefox-rendered context menus, especially on light-coloured webpages.
- Undo the context-menu background replacements introduced in v0.3.9 and v0.3.10, which made the entire background disappear on the user's macOS Zen setup. The new menu-only CSS sets only transparent panel border colour, removes the popup platform window shadow (the -moz-window-shadow: none CSS property), and removes the content-part border and CSS shadow. **No menu background, opacity, tint, colour scheme, blur, native popup appearance or corner radius is changed.** Removing the outer shadow could make the menu appear flatter.
- Keep **Zen Context Menu MOD** installed and its **Zen's own menus on macOS** preference enabled (widget.macos.native-context-menus=false), preserving menu item ordering, hidden items, icons, workspace gradients and the original glass effect. The HG Sine option is renamed **macOS 右鍵選單黑色邊線修正**, remains default-OFF, and can be turned on for direct hardware testing.
- Adopt the user's forward-looking version carry rule for all projects: minor and patch each run from 0 to 9, so v0.3.9 → v0.4.0; earlier published v0.3.10 is retained as history and is not renamed.

## SDR/HDR and Zia compatibility

- The adjustment only targets specific context-menu popups; all existing HG sidebar geometry, Zia and Zen Site Folders cards, Glance, URL popups, PiP, JavaScript, stream detection and SDR/HDR compositor code are unchanged. There are no new animation timers or browser-window compositor promotions.
- Existing Zia/HG overlay effects can still cause temporary HDR dimming or a washed out image during video playback on some macOS hardware. This release does not address those video behaviours. The Bilibili instant-glass option still deliberately bypasses SDR/HDR detection when enabled.

## Validation and hardware limitations

- GitHub CI checks Node.js syntax, all automated regression tests, release policy consistency and deterministic performance simulations before publishing. New and revised tests forbid CSS rules assigning menu background, transparency, colour, blur, appearance, radius or layout, while requiring scoped border/shadow changes and preserved Context Menu item ordering.
- **Actual macOS OLED SDR/HDR and visual testing not performed by CI.** The release is intended for direct user hardware testing, not a claim of confirmed appearance. Check white-background pages, dark video pages, all four rounded corners, nested menus and menu selection. Confirm that the translucent menu background and the Context Menu sorting remain unchanged. The macOS window's shadow may be part of the visible dark line; if its removal is insufficient or makes the menu too flat, switch the HG option OFF to restore the original style before reporting results.
